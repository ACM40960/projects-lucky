This project investigates two observable effects of rising atmospheric CO₂ using independent datasets. Xingnuo Li analyses the decline of Arctic September sea ice extent (1979–2025) using OLS regression, polynomial and exponential extrapolation, and Bayesian threshold forecasting. Nandini Hazarika analyses precipitation trends across 24 European and North African cities (1950–2025) using the Mann-Kendall test, Sen's slope and WMO baseline comparisons to test whether dry regions are getting drier and wet regions wetter. Both analyses use the same Mauna Loa CO₂ record and find statistically significant correlations with the same driver, connecting sea ice loss and water cycle intensification as two faces of the same climate change signal.
